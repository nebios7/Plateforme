# Transfert de Fichiers - App iOS

Application React Native pour transférer des fichiers sur iOS.

## Fonctionnalités

- Sélection de fichiers depuis le stockage
- Gestion des permissions (documents, galerie)
- Envoi de fichiers par email
- Support PDF, images, vidéos, archives

## Installation

```bash
npm install
npx expo start
```

## Test

```bash
npm run ios
```

## Dépendances

- expo-document-picker: sélection de fichiers
- expo-file-system: gestion du stockage
- expo-media-library: accès galerie
- expo-status-bar: barre d'état
